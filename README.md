*更新日志*

v1.6.1 · 2026.11.21

【功能更新】

①更换背景图片时可以自己选择显示图片的哪一部分，并支持预览

②每个清单可单独开关弹窗提醒，关闭后该清单不再弹出提醒

③长按卡片拖动时不再变暗，保留放大等效果

④设置里的“更多设置”新增“恢复默认设置”，可一键把设置恢复到默认状态

【Bug 修复】

①修复纯色渲染方案下圆角矩形里出现小块矩形的问题

②提醒改为常驻通知并支持锁屏全屏提醒，不会解锁后自动消失



v1.6.0 · 2026.11.14

【功能更新】

①更新了卡片渲染实现逻辑



v1.5.4 · 2026.11.14

【功能更新】

①事件备注新增文字备注，可与图片/文件一起保存、编辑和清空

②卡片渲染方案支持分别设置透明度；纯色方案还可设置填充颜色和描边

③选择纯色或液态玻璃后，在选项下方直接展开该方案的专属设置

④回收站支持按来源清单归类查看，并可一键恢复所有事件

【Bug 修复】

①修复拖动排序松手后卡片错位闪烁的问题

②修复长按卡片误弹出事件设置界面的问题

③修复拖动第一个事件后界面自动跳转的问题



v1.5.3 · 2026.11.11

【功能更新】

①优化了设置外观的层次逻辑和图案设计

【Bug 修复】

①修复拖动排序后无法把卡片放回原位的问题

②修复拖动卡片时内部玻璃渲染不随位置实时更新的问题



v1.5.2 · 2026.11.10

【功能更新】

①回收站卡片中的事件名称改为白色，其他文字颜色保持不变

②新增“回收站设置”二级页：保留自动删除事件、回收站保留时长、恢复事件保留时长

③已超过截止日期两天、再从回收站恢复的事件默认只再保留 12 小时，可自定义时长

④设置-外观重组为“背景”“圆角矩形卡片”“更多设置”，分别进入二级界面

⑤新增清单卡片与设置界面的字体颜色自定义，支持一键恢复默认颜色

⑥拖动排序时其他卡片实时跟随移动，并在长按时加入克制的放大反馈

【Bug 修复】

①修复拖动圆角矩形时其他卡片要松手后才移动的问题

②优化拖动排序的视觉反馈，避免长按放大时遮挡相邻卡片



v1.5.1 · 2026.11.9

【Bug 修复】

①修复垃圾桶图标的显示问题

②修复左滑卡片的卡顿问题



v1.5.0 · 2026.11.9

【功能更新】

①事件编辑页新增“备注”，可上传本地图片或文件，点击附件即用系统默认应用打开

②添加了左滑事件删除的快捷功能：左滑卡片弹出红色垃圾桶，点击即可删除

③新增回收站：从清单右上角“⋮”菜单进入，可恢复或彻底删除任务

④设置-数据管理新增回收站选项：可保留到期自动删除的事件，并调整保留时长（1-30 天）



v1.4.2 · 2026.11.9

【功能更新】

①列表顶部不再显示排序提示和“恢复默认排序”按钮，改为点击清单名右侧的“⋮”菜单恢复默认排序

②新增“更多设置”二级页面，卡片填充透明度与兼容渲染集中管理

③缩小顶栏高度；底部栏改为透明并缩小，仍保留可读性遮挡

④新建任务先选日期，默认时间 23:59；日期与时间选择相互独立

⑤长按整张卡片即可拖动排序，拖动时整张卡片变暗

⑥已截止未完成任务置顶显示，并显示 48 小时后移除的倒计时

⑦从设置返回清单页不再弹出清单选择，直接回到上次所在清单

⑧点击版本号可以查看本次更新日志

【Bug 修复】

①修复任务占满屏幕时，拖动最顶部任务导致界面突然跳转的问题

②修复拖动排序时卡片内文字跳动后又恢复的问题
